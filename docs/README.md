## Где что по требованиям кейса

| Требование | Где |
|---|---|
| Архитектура | [06_architecture.md](06_architecture.md), C4 в [diagrams/](diagrams/) |
| OpenAPI | [api/openapi.json](api/openapi.json); живой Swagger — http://localhost:8000/api/docs |
| Диаграмма статусов | [diagrams/application_state.md](diagrams/application_state.md); в коде — таблица переходов `backend/app/domain/state.py` |
| Модель данных | [06_architecture.md](06_architecture.md) §4; схема — `backend/migrations/001_init.sql` |
| Тестовые сценарии | [02_product.md](02_product.md) §8, [07_resilience.md](07_resilience.md) §6, [13_credit_mechanics.md](13_credit_mechanics.md) §8; автотесты — `backend/tests` по демо-миру `backend/seed/personas.yaml` |
| Коллекция запросов | в работе; пока — примеры в `backend/README.md` |
| Запуск одной командой | [README](../README.md) в корне |

Пути вида `refs/…` в документах — локальные копии первоисточников у команды, в репозиторий не входят: у каждого источника есть ссылка.
