# Alfa Horizon

Умный кредитный кабинет предпринимателя — Альфа Хак 2026, трек ММБ. Предприниматель описывает задачу бизнеса, а не заполняет анкету:
банк сам собирает данные из реестров, решает как опытный кредитный эксперт, объясняет решение и предлагает деньги раньше, чем они понадобились.

## Запуск

```bash
cd backend
docker compose up --build
```

| Адрес | Что |
|---|---|
| http://localhost:8000/api/docs | API; контракт — [`docs/api/openapi.json`](docs/api/openapi.json) |
| http://localhost:8081/__admin | WireMock: моки реестров, БКИ и банка в реальных форматах |
| `localhost:55432` | PostgreSQL |

Настройки — `backend/.env` (шаблон `backend/.env.example`; без файла подставятся значения по умолчанию).
Все компании и люди вымышленные; демо-мир — [`backend/seed/personas.yaml`](backend/seed/personas.yaml).

## Структура

| Папка | Что |
|---|---|
| [`backend/`](backend/README.md) | API и worker на FastAPI, движок решения и скоринг, политика в YAML, SQL-миграции, моки WireMock с генератором демо-мира, тесты |
| [`docs/`](docs/README.md) | документация: продукт, архитектура, движок, скоринг, деньги, право, устойчивость, контракты данных, диаграммы, OpenAPI |

## Состояние

**Готово:** данные из реестров (моки в форматах ФНС, ГИР БО и ЦБ) → факты → решение: стоп-факторы, продукт по отрасли, скоринг, ставка, лимит,
контрпредложение, полномочия → статус заявки и аудит; очередь кредитного специалиста; отказы источников на лету без перезапуска.

**В работе:** вход персоны и права «человек × компания», подпись и выдача, дозапрос и решение специалиста, радар кассового разрыва,
живой таймлайн, события мира в песочнице, проверка скоринга на синтетике.
